A. PENDAHULUAN

Dalam pengembangan aplikasi berbasis web yang dinamis, pengelolaan basis data (database) yang terstruktur merupakan aspek krusial. Framework Laravel menyediakan fitur Migration yang bertindak sebagai sistem version control untuk basis data. Fitur ini memungkinkan pengembang untuk membuat, memodifikasi, dan membagikan skema tabel secara programatis menggunakan sintaks PHP tanpa harus menulis query SQL secara manual. Selain itu, Laravel memiliki ORM (Object-Relational Mapping) bawaan bernama Eloquent yang mempermudah interaksi dengan basis data melalui representasi objek yang disebut Model..

B. LANGKAH KERJA & INSTALASI

1. Membuat Migration Untuk Tabel Major

Langkah pertama Menjalankan perintah php artisan make:migration create_majors_table di terminal untuk membuat file migrasi baru .

Pembuatan Table Major.

Selanjutnya Mendefinisikan skema pada fungsi up(). Tabel ini menggunakan id() sebagai primary key dan string('name') untuk menyimpan nama jurusan, beserta timestamps() bawaan Laravel untuk mencatat waktu pembuatan dan pembaruan data

fungsi pada bagian table major

2. Pembuatan File Migration Untuk Tabel Students

Membuat file migration baru menggunakan perintah Artisan php artisan make:migration_create_students_table. Mendefinisikan kolom atribut mahasiswa: nim dengan modifier unique() agar tidak ada duplikasi, name (string), dan address (text).

3. Pembuatan File Migrations Untuk Table Subject

Menjalankan perintah php artisan make:migration create_subjects_table. Tabel ini dirancang untuk menyimpan data mata kuliah dengan kolom name (string) untuk nama mata kuliah dan sks (integer) untuk bobot SKS.

4. Membuat Tabel Pivot Student_Subject (Implementasi Relasi N:M)

Untuk menghubungkan mahasiswa dan mata kuliah secara many-to-many, dibuat sebuah tabel pivot bernama student_subject. Skema ini berisi dua foreign key: student_id (merujuk ke tabel students) dan subject_id (merujuk ke tabel subjects).

5. Eloquent dan Controller

Membuat file Model bernama Product menggunakan perintah php artisan make:model Product. Model ini bertindak sebagai representasi objek tabel products sekaligus menjembatani interaksi data menggunakan fitur ORM Eloquent bawaan Laravel.

Membuat file controller bernama ProductController lewat perintah php artisan make:controller ProductController. File ini berperan sebagai pengatur logika bisnis aplikasi yang mempertemukan data (Model) dengan tampilan (View).

Di dalam ProductController, dibuat fungsi index() untuk menyiapkan data array lokal berisi daftar produk ('Laptop', 'Mouse', 'Keyboard'). Data tersebut kemudian dikirimkan (passing data) ke file view tertentu menggunakan fungsi compact('products')

6. Route

Langkah terakhir adalah mendaftarkan route baru pada file routes/web.php. Menggunakan metode HTTP GET dengan URL /products, rute ini diarahkan untuk memicu fungsi index yang ada di dalam ProductController. Rute inilah yang diakses pengguna melalui browser.

E. KESIMPULAN

Berdasarkan serangkaian langkah yang telah dilakukan, praktikum ini berhasil mengimplementasikan alur kerja backend development dalam membangun fitur pengelolaan data produk menggunakan framework Laravel. Melalui praktik ini, terlihat jelas bagaimana fitur Migration dan Seeder memberikan efisiensi yang tinggi dalam manajemen database. Migration bertindak sebagai version control yang memungkinkan pembuatan skema tabel secara terstruktur langsung melalui kode program, sementara seeder mempermudah proses pengisian data awal (dummy data) secara otomatis untuk kebutuhan pengujian sistem.
